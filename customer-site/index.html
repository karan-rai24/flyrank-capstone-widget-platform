About This Demo

This page demonstrates the FlyRank widget running from a different origin than the API.

API Origin: http://localhost:8000

Customer Origin: http://localhost:5500

  • Widget loads via script tag from API
  • Config fetched via public endpoint
  • Submissions sent to public API
  • CORS headers enable cross-origin requests
